# Fonts for synthetic Cyrillic OCR training data.
#
# One direct raw-download URL per line (TTF/OTF, variable fonts with
# [axis] tags are fine). Every entry below was verified locally with
# fontTools (getBestCmap contains both 'А' U+0410 and 'я' U+044F)
# before being added here — see scripts/download_fonts.py for the
# same check applied at download time.
#
# Source: github.com/google/fonts (raw.githubusercontent.com), main
# branch. Filenames match the current OFL/UFL folder layout as of
# 2026-09; Google periodically reshuffles static files into variable
# [wght]/[wdth,wght] files, so if a URL 404s, re-check the family's
# folder at github.com/google/fonts/tree/main/ofl/<family>.
